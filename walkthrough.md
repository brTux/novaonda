# Nova Onda - Identidade Visual Hotmart 🍊

O sistema foi totalmente migrado para a paleta de cores oficial da Hotmart, focando em profissionalismo, clareza e conversão.

## Mudanças Realizadas 🎨

### 1. Paleta de Cores Hotmart
- **Cor Primária**: Implementamos o Laranja Hotmart (`#ff5100`) para todas as ações principais, botões e estados ativos.
- **Fundo & Superfícies**: O fundo foi alterado para um cinza ultra-claro suave (`#f7f8f9`), e os cards agora utilizam o padrão de bordas sutis e sombras leves da Hotmart.
- **Tipografia**: O texto agora utiliza um Dark Slate profissional (`#2d3339`), garantindo alto contraste e leitura confortável.

### 2. Tipografia Normalizada 📏
- **Ajuste de Escala**: Reduzimos o tamanho das fontes que estavam excessivamente grandes. Agora o sistema segue uma hierarquia tipográfica padrão de SaaS profissional.
- **Legibilidade**: Títulos e textos de apoio foram ajustados para não sobrecarregar a visão do usuário, mantendo um visual limpo e moderno.

### 3. Navegação 100% Responsiva & Estilizada 📱
- **Novo Menu**: Removemos a barra de pesquisa para dar foco total às ferramentas de gestão.
- **Mobile-First**: O menu superior agora é totalmente responsivo, incluindo um menu lateral (hamburger) para dispositivos móveis, garantindo que você gerencie seus bots de qualquer lugar.

### 4. Otimização de Layout & Densidade 🎯
- **Chat Compacto**: A página de Chat foi completamente otimizada com elementos menores, bolhas de mensagem mais compactas e sidebar reduzida (72px de largura), permitindo visualizar mais conversas simultaneamente.
- **Densidade Profissional**: Todos os componentes foram ajustados para maximizar a quantidade de informação visível na tela sem necessidade de rolagem excessiva.
- **Espaçamento Inteligente**: Paddings e margens foram refinados para criar um equilíbrio entre densidade e respiração visual.

### 5. Editor de Fluxo & Ferramentas
- Todo o **Flow Builder** e os **Criadores de Conteúdo** (Pressell, Checkout, Obrigado) foram adaptados para a nova estética, mantendo a funcionalidade avançada em um ambiente mais familiar e intuitivo.

## Como Executar
```bash
npm run dev
```
1. Explore o novo Dashboard com o visual Hotmart.
2. Teste o menu responsivo reduzindo a largura do navegador.
3. Acesse o Chat ao Vivo para ver a nova densidade otimizada.
